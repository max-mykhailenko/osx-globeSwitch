## Selected-text correction in Chromium applications

GlobeSwitch now requests Chromium's accessibility interface when an app does not expose its focused field and does not support Electron's accessibility activation attribute. This resolved the reported correction failure in ChatGPT Work during the user's manual test.

- Tries `AXEnhancedUserInterface` only when `AXManualAccessibility` is explicitly unsupported, once per app launch.
- Preserves the current keyboard layout if the first activation request succeeds but the focused field is not ready yet. Allow about three seconds before selecting the text and trying again.
- Reads alternative selection text even when the numeric range is collapsed or the direct text response is empty.
- Shows the reason when **Correct Selected Text & Switch** is disabled.
- Keeps password-field exclusions, focus checks, clipboard restoration, and the normal Paste/Undo path. No selected text is logged.

## Install

Use **GlobeSwitch-0.3.2-arm64.dmg** and drag GlobeSwitch into Applications. Requires Apple Silicon and macOS 14 or later, Input Monitoring, and Accessibility for text correction. Set **Press Globe key to → Do Nothing**.

The installer is ad-hoc signed and is not Apple-notarized. Checksums are in `release/SHA256SUMS.txt`.
