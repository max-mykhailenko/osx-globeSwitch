## Globe corrects selected text

Select text typed using the wrong keyboard layout and press Globe/Fn. GlobeSwitch replaces the selection using the next layout in your configured cycle, then activates that layout. With no selection, Globe continues to switch languages normally.

- Keyboard-layout correction for **ABC ↔ Ukrainian-PC**, including uppercase and keyboard punctuation.
- **Correct Selected Text & Switch** is also available in the menu. No separate hotkey is needed.
- Local processing, focus checks before replacement, clipboard restoration, and the host application's normal Paste/Undo path.
- New **Fold** app icon with macOS icon sizes from 16 to 1024 pixels.

## Install

Download **GlobeSwitch-0.3.1-arm64.dmg** below and drag GlobeSwitch into Applications.

Requires **Apple Silicon and macOS 14 or later**. Set **Press Globe key to → Do Nothing** in Keyboard settings and grant **Input Monitoring**. Selected-text correction also requires **Privacy & Security → Device Control and Data Access** on macOS 27, or **Accessibility** on earlier versions.

If permission is visibly enabled but correction does not run after an update, the saved permission may reference an older app signature. Refresh the app-specific permission record and add the installed `/Applications/GlobeSwitch.app` again.

The installer is ad-hoc signed and is not Apple-notarized. A SHA-256 checksum is attached for download verification. Password fields and custom controls that do not expose their selection are not supported for correction.
