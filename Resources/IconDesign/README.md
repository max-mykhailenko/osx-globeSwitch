# Fold app icon

Selected by the user on 2026-09-15: option 2, Fold. Created using the built-in
image-generation tool. The selected artwork is retained in `Fold-original.png`.
`script/build_icon.sh` resizes this artwork into standard macOS ICNS sizes
(16–1024 px) and updates `Resources/AppIcon-1024.png` and `Resources/AppIcon.icns`.

This is a static raster icon inspired by the contemporary glass aesthetic;
it is not an Icon Composer layered icon with system-rendered glass variants.
The menu-bar input-source indicator continues to show the active language.

## Generation prompt

a tiny keyboard utility that switches English/Ukrainian layouts with the Globe
key and repairs selected wrong-layout text. Contemporary macOS 27 / refined
Liquid Glass aesthetic, quiet and exceptionally simple, strong silhouette
readable at 32px. Square 1024x1024 image, centered upright rounded-square icon
occupying 82% of canvas, on a uniform pale neutral gray presentation background.
Straight-on orthographic view. Subtle translucent depth and soft edge highlights,
not inflated shiny plastic, not vintage Aqua. Only one large abstract symbol,
generous negative space. No captions, no labels, no letters, no flags, no Apple
logo, no mockup devices, no little decorative details, no large drop shadows.
This is a NEW alternative design, not an edit of any previous image.

Very pale ice-blue frosted rounded-square base. Central broad continuous ribbon
making a single elegant S-shaped folded turn, abstracting the act of switching
between two states. One face deep indigo, the returning face soft cyan with
restrained glass translucency at the fold. Sculptural but extremely simple, two
broad curved strokes only, a uniquely recognizable compact mark, no sphere,
no conventional arrows.
