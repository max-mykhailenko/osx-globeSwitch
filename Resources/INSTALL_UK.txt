GlobeSwitch — встановлення на macOS
===================================

1. Перетягніть GlobeSwitch.app до папки Applications.

2. Перший запуск:
   - відкрийте Applications;
   - натисніть GlobeSwitch правою кнопкою;
   - виберіть Open / Відкрити;
   - підтвердьте запуск.

   Застосунок підписаний локальним ad-hoc підписом і не нотаризований Apple,
   тому звичайний подвійний клік під час першого запуску може бути заблокований.
   Якщо Open не допоміг, відкрийте System Settings → Privacy & Security,
   знайдіть повідомлення про GlobeSwitch і виберіть Open Anyway.

3. У System Settings → Keyboard → Text Input → Edit… додайте щонайменше дві
   потрібні розкладки або системні джерела введення. Підтримуються також
   регіональні варіанти, наприклад British English.

4. У System Settings → Keyboard встановіть:
   Press Globe key to → Do Nothing.

5. Запустіть GlobeSwitch. У menu bar відкрийте його меню та виберіть
   Request Keyboard Access… . У System Settings → Privacy & Security →
   Input Monitoring увімкніть GlobeSwitch. Для виправлення виділеного тексту
   також увімкніть GlobeSwitch у Privacy & Security → Device Control and Data Access
   (у попередніх версіях macOS цей розділ називається Accessibility).
   Якщо система попросить — перезапустіть GlobeSwitch.

6. У меню GlobeSwitch → Input Sources in Globe Cycle позначте галочками
   джерела, які потрібно перемикати по колу. Має залишатися щонайменше два.

7. Перевірте цикл у TextEdit. У меню GlobeSwitch має бути статус
   Globe monitor: Active (switch on key-down).

8. Лише після копіювання до Applications виберіть Enable Launch at Login.
   LaunchAgent зберігає абсолютний шлях до застосунку.

Важливо
-------

- Поки GlobeSwitch активний, Globe/Fn працює як спеціальна клавіша мови.
  Для системних Fn-комбінацій тимчасово виберіть Pause Globe Switching.
- Якщо після оновлення Globe monitor не активний, вимкніть і знову ввімкніть
  GlobeSwitch у Input Monitoring.
- Інсталятор призначений для Apple Silicon (arm64) і macOS 14 або новішої.

Виправлення розкладки виділеного тексту (0.3.0):
Надайте GlobeSwitch доступ у System Settings → Privacy & Security → Device Control and Data Access
(Accessibility у попередніх версіях macOS).
Без виділення Globe перемикає мову. З виділенням — виправляє текст відповідно до
наступної розкладки в циклі, а потім перемикає мову. Підтримується ABC ↔ Ukrainian-PC.
Альтернатива: пункт меню Correct Selected Text & Switch. Окремої гарячої клавіші немає.

Якщо дозвіл увімкнений, але виправлення не працює після оновлення, оновіть запис
дозволу й додайте саме /Applications/GlobeSwitch.app: старий запис може посилатися
на підпис попередньої версії.
